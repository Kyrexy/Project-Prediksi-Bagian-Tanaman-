# Penyimpanan dataset

Notebook membaca dataset dari **Google Drive**:

```
MyDrive/dataset_tanaman/
├── train/{akar,batang,buah,daun}/
├── val/{akar,batang,buah,daun}/
```

Folder lokal ini hanya dokumentasi. Anda dapat menyimpan salinan dataset di sini, tetapi notebook tidak membacanya otomatis. Jangan masukkan data gambar besar ke Git.
